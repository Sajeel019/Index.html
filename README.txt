# Birthday Surprise Website for M I N E 🤍

## Files
- `index.html` — the page structure and love letter
- `style.css` — pink romantic styling and animations
- `script.js` — candles, envelope, hearts and interactions
- `romantic-music.mp3` — optional music file you add yourself

## Run on Windows
1. Extract `birthday-surprise-website.zip`.
2. Open the extracted `birthday-surprise` folder.
3. Double-click `index.html`. It should open in your browser.
4. For editing, open the folder in Visual Studio Code and edit the three files.

## Add background music
The browser will only start music after the visitor taps **Open your surprise**.
Add an MP3 you have permission to use to this same folder and name it exactly:
`romantic-music.mp3`
Refresh the page. If you do not add this file, the rest of the website still works.

## Personalize
- The recipient's name is currently displayed as `M I N E 🤍`.
- The signature appears as `Your love AbuBakar`.
- Edit the text in `index.html` to change the letter or messages.

## Important
Google Fonts are loaded online. The page still works without them, using fallback fonts.
